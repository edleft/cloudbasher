# Contributions

CloudBasher is maintained as a source-available security research project.
Copyright (c) 2026 edleft. See [`LICENSE`](LICENSE).

Substantive public pull requests are not accepted. This repository is a published
distribution of a private development repository, and changes flow one way, from
private to public — so a pull request here has nowhere upstream to land.

That is a workflow constraint rather than a policy on outside input. Issues and
Discussions are open, and a well-described bug or a reproduction is more useful than
a patch that cannot be merged.

## Where to send what

Pick by what the message is, not by which channel is quickest:

| What | Where |
|---|---|
| Bugs, defects, technical problems | this repository's **Issues** |
| Questions, general inquiries | this repository's **Discussions** |
| **Security vulnerabilities** | **Security** → **Advisories** → **Report a vulnerability** |
| Licensing, authorization requests, private matters | <cloudbasher@edleft.org> |

**Never file a security report as an Issue or a Discussion.** It is world-readable the
moment it is submitted and cannot be un-read. See [`SECURITY.md`](SECURITY.md).

Requests for the separate written authorization that the licence requires for
commercialization or for training externally available AI systems go to the licensing
address above, not to a public channel. See [`LICENSE`](LICENSE) section 21.
